Activity Monitored

Keeps your Mac quick when too much is running at once.

Download for Mac ↓.zip · 18 KBView the code

What it does

Your Mac’s processor can only do so much at once. When a backup, a photo sync and a software update all run together, they compete with the app you are actually using, and everything starts to stutter: typing lags, videos skip, windows beachball.

Activity Monitored watches for that moment. When the processor is overloaded, it gently lowers the priority of the busy programs running in the background. They keep working, just a little more politely, and the window in front of you stays smooth. Once things calm down, every program goes back to normal.

How it works

1. It watches the load

Every 3 seconds it checks how hard the processor is working and which programs are using it most. If there is spare room, it does nothing at all.

2. It lowers busy background programs

When the Mac is overloaded, it moves the heaviest background programs to macOS’s low priority lane, the same one macOS uses for its own background chores. Nothing is closed or paused, and no work is lost.

3. It always puts things back

Every change starts its own 90 second timer that reverses it automatically. The timer runs separately, so even if Activity Monitored crashes or you remove it, your programs still return to normal. Every change is also written to a log you can read.

Why it’s useful

  • 01
    The app you’re using stays smoothTyping, scrolling and video keep up even while heavy work runs behind them.
  • 02
    Heavy jobs can even finish soonerIn one overload test on one Mac, a 10 program job finished in 24 seconds instead of 39.
  • 03
    Nothing is ever closedPrograms are only slowed for a moment. They keep running and keep their work.
  • 04
    Free, private, no accountNo subscription, no sign up, and no data leaves your Mac.

How to install

    That’s itIt starts now and every time you log in. If your Mac offers to install developer tools, click Install, then repeat step 2.
