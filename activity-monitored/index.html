Activity Monitored

Keeps your Mac quick when too much is running at once, and keeps room free on your disk without deleting anything.

Download for Mac ↓View the code

Double-click the zip in Downloads, then double-click Install Activity Monitored.command. The first time, macOS blocks it because it is not from the App Store: open System Settings, Privacy & Security, scroll down, click Open Anyway, then double-click it again. It runs in the background from then on; type monitored in Terminal to see what it did.

What it does

Your Mac’s processor can only do so much at once. When a backup, a photo sync and a software update all run together, they compete with the app you are actually using, and everything starts to stutter: typing lags, videos skip, windows beachball.

Activity Monitored watches for that moment, and you never see it. When the processor is overloaded, it lowers the priority of the busy programs running in the background. When memory runs out, it pauses the background program using the most memory until memory recovers. When the disk fills up, it makes room by compressing big files you have not touched in days, so nothing is deleted. Once things calm down, every program goes back to normal. It never shows a pop-up.

How it works

1. It watches the load

Every 3 seconds it checks how hard the processor is working and which programs are using it most. If there is spare room, it does nothing at all.

2. It lowers busy background programs

When the Mac is overloaded, it moves the heaviest background programs to macOS’s low priority lane, the same one macOS uses for its own background chores. No work is lost. It never closes or deletes anything.

3. It always puts things back

Every change starts its own 90 second timer that reverses it automatically. The timer runs separately, so even if Activity Monitored crashes or you remove it, your programs still return to normal. Every change is also written to a log you can read.

4. It stops memory from running out

When memory runs short, it pauses the background script, build or server using the most memory, so it stops taking more. The paused program keeps everything it was doing. It resumes as soon as memory recovers, and a separate timer resumes it within 2 minutes even if Activity Monitored crashes. Apps with a window, calls, music and the app in front are never paused.

5. It keeps room free on your disk

macOS needs free disk space to move memory onto the disk. With too little, apps freeze and you end up force quitting them. Activity Monitored keeps at least 30 GB free (you can pick the number). Below that, it turns on the compression macOS uses for its own files, for big files you have not changed in 3 days. Nothing is deleted, and every file opens exactly as before. Each file is copied, checked byte for byte, and swapped in only if it is not open and did not change. Every compressed file is listed, and it reverses itself once there is plenty of room.

6. It stops the disk from filling while it works

If space keeps dropping because memory is spilling onto the disk, it pauses the program using the most memory until there is room again. If the disk is almost full, it pauses the program writing the most. A paused program keeps all its work, continues where it stopped, and is never held for more than 3 hours.

Why it’s useful

  • 01
    The app you’re using stays smoothTyping, scrolling and video keep up even while heavy work runs behind them.
  • 02
    Heavy jobs can even finish soonerIn one overload test on one Mac, a 10 program job finished in 24 seconds instead of 39.
  • 03
    Apps keep runningApps are only slowed or paused for a while and keep their work. Nothing is deleted. A background script holding gigabytes of swap on a nearly full disk can be ended, and its command is saved to rerun.
  • 04
    Free, private, no accountNo subscription, no sign up, and no data leaves your Mac.
