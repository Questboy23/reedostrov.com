Activity Monitored

Stops the “Your system has run out of application memory” window that pauses your apps.

Download for Mac ↓View the code

Double-click the zip in Downloads, then double-click Install Activity Monitored.command. The first time, macOS blocks it because it is not from the App Store: open System Settings, Privacy & Security, scroll down, click Open Anyway, then double-click it again. It runs in the background from then on; type monitored in Terminal to see what it did.

What it does

When RAM is full, macOS moves memory into swap files on your disk. When the disk is nearly full, it can’t make more swap, so it pauses your apps and lists them in red. Activity Monitored keeps that from happening.

How it works

1. It keeps disk room for swap

Once a minute it checks free disk space. Below the target (30 GB, you can pick the number) it runs the official cleanup commands of uv, pip and npm. Each one deletes only that tool’s download cache, which the tool downloads again when needed. Nothing else is ever deleted, and monitored clean off turns it off.

2. It warns you before apps freeze

Under 15 GB free, or when memory stays critical for 30 seconds, it shows a notification banner. The memory banner names the 3 biggest programs so you can quit one. At most one banner per kind every 30 minutes. Under 10 GB free, or with memory exhausted, it also shows an alert that closes itself after 60 seconds, because Focus mode hides banners.

3. It keeps the app in front smooth

When the processor is over 75% busy, it moves busy background command-line programs to macOS’s low priority lane. Apps with windows, Logic, music, calls and Claude are never touched. Each one returns to normal when the processor calms down, after 10 minutes at most, and by a separate timer even if Activity Monitored crashes.

What it never does

It never pauses, quits, kills or rewrites any program or file. It can’t free space your own files take, and it can’t add RAM: if your files fill the disk or too many big programs are open, it tells you.

How to install

  1. 1
    DownloadClick Download for Mac above, then double-click the zip in your Downloads folder to unzip it.
  2. 2
    Open the installerIn the unzipped folder, right click Install Activity Monitored.command and choose Open.
  3. 3
    That’s itIt starts now and every time you log in. If your Mac offers to install developer tools, click Install, then repeat step 2.

Or paste this single line into Terminal:

curl -fsSL https://raw.githubusercontent.com/Questboy23/activity-monitored/main/install.sh | bash
