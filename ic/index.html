Project 05 · macOS · v1.0

IC

Your files, smaller. Double-click one and it opens back exactly the same, byte for byte.

Download for Mac ↓

IC.dmg, 114 MB. Apple Silicon Macs with macOS 26 or newer. Open it and double-click Install IC.command. The first time, macOS blocks it because it is not from the App Store: open System Settings, Privacy & Security, scroll down, click Open Anyway, then double-click it again. No password needed.

What it does

Your Mac already has files that could be much smaller without losing anything. IC packs each one with whichever free, well-known packing tool shrinks that file the most, and remembers which tool it used. When you open the file, IC runs that tool backward and you get the exact original.

If packing a file would save less than about half a percent, IC leaves it alone.

How it works

1. A bunch of algorithms stored on your computer

The download carries 17 existing packing tools. A packed file never carries a tool. It keeps a label of about 100 bytes that names the tool and its settings.

2. It picks the best way per file

4 tools race on each file at the same time, and the smallest result wins. Photos, music, text and PDFs each get the tools that suit them. Big files get a quick test on 4 small slices first, so slow tools only run when they might win.

3. It improves itself

Every night it keeps score of which tool won for each kind of file and stops trying tools that never win. That cut its work by 35% with no size lost.

4. It builds its own algorithms

Once a week it changes a packing recipe a little at a time, and keeps a new recipe only if it wins on files it never saw. One kept recipe is 2% smaller than the best built-in setting on data files.

5. Three versions

Fast for speed, everyday for normal use, and max for files you rarely open.

How to install

  1. 1
    DownloadClick Download for Mac above. Open IC.dmg from your Downloads folder.
  2. 2
    InstallDouble-click Install IC.command. Everything goes in your own home folder.
  3. 3
    Save a file smallerIn Finder, right-click any file, choose Quick Actions, then Save as .ic.
  4. 4
    Open itDouble-click the .ic file. You get the original back, exactly.
  5. 5
    Optional: automatic packingTurn it on in the IC Files app. It runs at 1:00 AM, only when the Mac is plugged in and idle.

To remove IC, run bash "Install IC.command" --uninstall. Everything goes to the Trash.
