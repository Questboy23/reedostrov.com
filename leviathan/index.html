Project 01 · macOS · v2.0

Leviathan

It stops malware on your Mac before the malware can run.

Download for Mac ↓View the code

Double-click the zip in Downloads, then double-click Install Leviathan.command. The first time, macOS blocks it because it is not from the App Store: open System Settings, Privacy & Security, scroll down, click Open Anyway, then double-click it again. It needs Homebrew and your Mac password. The shield appears in your menu bar.

What it does

Most Mac infections start in one of three ways: a fake website, a file you download, or a command a scam page talks you into pasting into Terminal. Antivirus apps usually scan files after they arrive. Leviathan also stands guard at the other two doors.

It runs quietly in the background. After a one minute setup there is nothing to click and nothing to keep up to date. When it does step in, it tells you in plain words what it found and why, and it keeps a record so you can reverse the action later.

How it works

1. Bad websites never load

Leviathan adds a standard macOS profile that sends every website lookup, encrypted, to Cloudflare’s security service (1.1.1.2). Known malware and phishing sites simply fail to load, in every app. Your network provider cannot read the lookups. You turn it on with one click and your Mac password, and remove it any time in System Settings.

2. Harmful downloads get locked away

New files in Downloads and new apps are checked with the same malware rules Apple ships in macOS, plus Apple’s list of developers it has banned. A match moves to a locked folder where it cannot open. You can put it back for 7 days.

3. Sneaky startup items get switched off

Some malware hides by adding itself to the list of programs that start when you log in, often pretending to be part of macOS. Leviathan looks for those disguises and turns them off.

4. Dangerous pasted commands get paused

A popular scam shows a fake error and asks you to paste a line into Terminal to “fix” it. That line installs malware. Leviathan recognises these commands, stops them once and explains the risk. If you really meant it, pressing Enter again runs it.

5. Fake password boxes get closed

Some malware pops up a box asking for your Mac password. Leviathan closes those boxes. One you open yourself in Terminal is allowed.

6. It watches AI agents, if you want

Turn on “Watch AI agents” in the menu. Leviathan plants fake secret files; if anything reads one while Claude Code, Codex or another agent runs, you get a notification naming the agents. One click pauses every AI agent at once. It also warns when an AI tool is set to run commands without asking you.

7. A shield in your menu bar

White while Leviathan waits, green while a scan runs, orange when it has a warning you have not seen. Copying text never triggers anything.

How to install

  1. 1
    DownloadClick Download for Mac above, then double-click the zip in your Downloads folder to unzip it.
  2. 2
    Open TerminalPress Cmd and Space, type Terminal, press Return.
  3. 3
    Run the installerType bash with a space, drag install.sh from the unzipped folder into the window, and press Return. No password needed.
  4. 4
    Turn on the website filterSystem Settings opens at the end. Double-click Leviathan website filter, click Install, and enter your Mac password.

Or paste this single line into Terminal:

cd ~ && curl -fsSL https://github.com/Questboy23/leviathan/archive/refs/tags/v2.1.1.tar.gz | tar xz && bash leviathan-2.1.1/install.sh
