Leviathan

It stops viruses on your Mac before they run.

Download for Mac ↓View the code

Double-click the zip in Downloads, then double-click Install Leviathan.command. The first time, macOS blocks it because it is not from the App Store: open System Settings, Privacy & Security, scroll down, click Open Anyway, then double-click it again. It needs Homebrew. The shield appears in your menu bar.

What it does

Leviathan checks everything new on your Mac for viruses: downloads, apps, and programs that set themselves to start at login. It also stops scam commands pasted into Terminal, and blocks known malware websites in every app.

It runs a check every hour and whenever your Downloads, Applications or startup folders change. The rest of the time it uses no CPU. When it steps in, it tells you what it found and why, and every action can be undone.

How it works

1. Harmful downloads get locked away

New files in Downloads and new apps are checked with the same malware rules Apple ships in macOS (XProtect), Apple’s list of developers it has banned, and a list of known malware sites the file came from. A match goes to the Trash with its permission to run removed, so it cannot open even from there. leviathan undo puts it back. Apps Apple never checked are only noted in the log, because unsigned does not mean harmful.

2. Fake startup items get switched off

A program that sets itself to start at login while pretending to be Apple, or hides unsigned in a secret folder, is switched off and moved out. Undoable.

3. Pasted scam commands get stopped

A popular scam asks you to paste a line into Terminal to “fix” something. Leviathan stops commands that download and run code, unscramble hidden code, remove Apple’s safety check, or draw a fake password box. It explains the risk once; press Enter again to run it anyway.

4. Bad websites never load

A standard macOS profile sends every website lookup, encrypted, to Quad9 (9.9.9.9). Known malware and phishing sites fail to load, in every app. Legal sites stay open. Remove the profile in System Settings any time.

5. Is this a virus?

leviathan check File answers in plain words. leviathan pkg File.pkg shows what an installer’s scripts will do before you run it.

6. A shield in your menu bar

White while Leviathan waits, green while a scan runs, orange when it has a warning you have not seen.

How to install

  1. 1
    DownloadClick Download for Mac above, then double-click the zip in your Downloads folder to unzip it.
  2. 2
    Open TerminalPress Cmd and Space, type Terminal, press Return.
  3. 3
    Run the installerType bash with a space, drag install.sh from the unzipped folder into the window, and press Return. No password needed.
  4. 4
    Turn on the website filterSystem Settings opens at the end. Double-click Leviathan website filter, click Install, and enter your Mac password.

Or paste this single line into Terminal:

cd ~ && curl -fsSL https://github.com/Questboy23/leviathan/archive/refs/tags/v4.0.0.tar.gz | tar xz && bash leviathan-4.0.0/install.sh
