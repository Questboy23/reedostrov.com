Project 01 · macOS

Leviathan

It stops malware on your Mac before the malware can run.

Download for Mac ↓View the code

What it does

Most Mac infections start in one of three ways. A fake website, a file you download, or a command a scam page tells you to paste into Terminal.

Leviathan watches all three. It runs in the background, so after setup there is nothing to click.

Why it helps

  • 01
    Blocks known bad websitesYour Mac checks every site against lists of malware and phishing addresses, refreshed every hour.
  • 02
    Catches harmful downloadsNew files are checked with Apple's own malware rules. Matches move to a folder where they cannot run.
  • 03
    Stops dangerous pasted commandsIf a page tricks you into pasting a command that installs malware, Leviathan stops it once and explains why.
  • 04
    Everything can be undoneEach action is logged. One command puts any file or setting back the way it was.
  • 05
    Free, with no accountNo subscription, no sign up, and nothing about you is sent anywhere.

How to install

  1. 1
    DownloadClick Download for Mac above. Your Mac unzips it into Downloads.
  2. 2
    Open TerminalPress Cmd and Space, type Terminal, press Return.
  3. 3
    Run the installerType bash with a space, drag install.sh from the unzipped folder into the window, and press Return. Enter your Mac password when asked.

Or paste this single line into Terminal:

cd ~ && curl -fsSL https://github.com/Questboy23/leviathan/archive/refs/tags/v1.0.0.tar.gz | tar xz && bash leviathan-1.0.0/install.sh
